# Диагностика и известные ограничения

[К оглавлению](../README.md)

## 1. Порядок диагностики

Сначала сохраните полный журнал кнопкой «Копировать». Запишите выбранные VCCQ, шину, пресет, частоту, область и размер файла. Отличайте ошибку init от ошибки стирания, передачи или readback: одинаковый WinError в разных фазах имеет разное значение.

Если операция завершилась ошибкой записи, её данные нельзя считать ни полностью старыми, ни полностью новыми. Выполните чтение и сравнение перед использованием чипа. Повторное нажатие записи при включённом стирании снова удаляет всю выбранную область.

## 2. Сообщения и действия

| Сообщение/симптом | Значение и следующий шаг |
|---|---|
| T48 не найден или занят | Проверьте USB, драйвер WinUSB, доступность T48 и закройте другую утилиту/операцию |
| Ошибка 0x21 при init | Не подтверждена начальная инициализация; проверьте подключение и питание, попробуйте ручной 8 МГц |
| Ошибка CID/CSD | Ответ неполный или с неверным статусом; успех CID сам по себе не подтверждает рабочее чтение данных |
| Авто: кандидат не прошёл проверку | Нормально, если затем выбран проверенный вариант; если не прошёл ни один 8-МГц пресет — проверьте подключение |
| GPT/MBR не обнаружена | Может быть пустая память, другой формат или повреждённая разметка; проверьте отчёт и чтение LBA 0 |
| Файл больше области | Неподходящий образ или неверная ёмкость; не обходите проверку, уточните назначение файла |
| Файл меньше области | Допустимо, но предварительное стирание удалит остаток области |
| Последний блок выходит за границу | Размер с округлением до 16 КиБ не помещается; подготовьте корректный образ |
| Раздел не выровнен по группе стирания | Нельзя безопасно применить данный путь предварительного стирания к этим границам |
| Контроль стирания: ожидалось 00/FF | До записи найден другой байт или неполное чтение; запись блокируется |
| Ошибка верификации образа | Прочитанные данные отличаются; успех записи не подтверждён |
| CID изменился | Другая идентичность после перезапуска/перед настройками; операция блокируется |
| EXT_CSD изменился | Исходный снимок устарел; снова выполните init/чтение регистра |
| Уже выполняется операция | Дождитесь завершения или обработанного STOP |

Проверка пайки, контактов, длины проводов и питания относится к аппаратной диагностике. Приложение не может программно доказать качество сигнала или правильность распиновки.

## 3. WinError 121 и перезапуск

WinError 121 — тайм-аут USB/ожидания в соответствующем вызове, а не доказательство повреждения eMMC.

В известном случае после записи BOOT1 операция падала на чтении подтверждения power-off перед верификацией. Текущий `restart` при коде 121 только в этом месте переоткрывает USB и заново проверяет init/CID. Затем требуется обычное сравнение данных. Сообщение «повторное открытие USB после тайм-аута ответа T48» описывает восстановление, а не успешную верификацию.

Если ошибка возникает при передаче данных, init, чтении регистров или повторном открытии, этот специальный обход её не скрывает. Уменьшите частоту для диагностики, проверьте контакты/USB и сохраните точную фазу ошибки.

При финальном закрытии power-off выполняется best effort, его ошибка скрыта, USB освобождается. Это сделано для завершения операции без повторяющегося предупреждения. Отсутствие предупреждения не является подтверждением снятия питания.

## 4. High-Speed и экспериментальный Legacy

На проверенной THGA-конфигурации стандартные High-Speed 30 МГц воспроизводимо могли давать неверный CSD, тогда как возврат HS_TIMING=0 позволял читать данные. Автоподбор отклоняет неудачные варианты и может выбрать THGA Legacy 30.

Legacy на номинальных 30 МГц превышает предел 26 МГц обычного режима. Это экспериментальный разгон. DEVICE_TYPE с YES для 52/200/400 МГц не гарантирует совместимость текущего T48/адаптера/последовательности на таких частотах. При сомнениях используйте ручной 8 МГц и повторную верификацию.

## 5. STOP и восстановление доступа

Не ожидайте мгновенного разрыва текущего потока записи: его нужно завершить, чтобы T48 не остался ждать недостающие данные. Дождитесь возврата интерфейса в свободное состояние. Если T48 не отвечает после завершения, закройте конкурирующие программы, проверьте соединение и при необходимости переподключите устройство. Не считайте прерванный образ рабочим без нового чтения/проверки.

Возобновление с последнего байта, автоматическое восстановление старых данных и транзакционный откат не реализованы.

## 6. Интерфейс и файлы

- В «Авто» ручная частота недоступна — это ожидаемое поведение.
- После смены чипа нужен новый «Инит eMMC»; кеш не привязан к CID.
- При нескольких подходящих именах образов задайте файл вручную.
- Userdata целой области и Android-раздел userdata имеют разные размеры и назначение.
- Фильтр журнала может скрыть нужные строки; для анализа выберите «Все» либо скопируйте полный журнал.
- 100% относится к фазе, а не обязательно ко всему сценарию. Итог определяется сообщениями об ошибках и верификации.
- EXE не требует внешнего Python, но использует драйвер USB и графические библиотеки Windows.
- При frozen-ошибке USER_BASE/NoneType используйте актуальную сборку с runtime hook, а не старый debug-EXE.

## 7. Ограничения текущего кода

| Область | Ограничение |
|---|---|
| Sparse | FILL не разворачивается, DONT_CARE пропускается, CRC не проверяется; верифицируются только выбранные RAW-сегменты |
| Полная запись областей | Принимает байты файла как RAW; Sparse не декодируется |
| Меньший образ | Верификация не охватывает остаток аппаратной области |
| Контроль стирания | Для больших областей читаются первые 32 МиБ |
| Ручное стирание | Без readback; тайм-аут готовности может сопровождаться продолжением и итоговым сообщением успеха |
| Диапазон без предварительного стирания | Возможны обрезка/пропуск выходящих сегментов и округление передачи за невыровненный конец |
| EXT_CSD readback | Несовпадения логируются, план продолжается; общий успех не отменяет ошибки отдельных полей |
| GPT | Нет проверки CRC/резервного GPT; разбор ограничен буфером и 128 записями |
| MBR | Четыре первичные записи, без обхода EBR |
| Файловые системы | Распознавание сигнатур, без монтирования/ремонта |
| RPMB | Пробный статус, без полноценного authenticated read/write и работы с ключами |
| GPP | Нет операций общего назначения; отчёт GPP выводит фиксированные нули |
| Частоты | 40 МГц исключены; реальные сигналы инструментально не измерялись |
| Настройки | Нет постоянных пользовательских профилей и CID-привязанного кеша |
| Тесты | Два известных GUI assertion failure, подробности в TESTING.md |
| Выпуск | Нет автоматической версии, lock-файла и подтверждённой чистой установки |

Эти ограничения зафиксированы по коду; написание документации не изменяло их реализацию.

## 8. Что приложить к сообщению об ошибке

Укажите источник запуска (EXE или Python), дату сборки/изменений, модель/идентификацию чипа, выбранные параметры, фазу и полный журнал. Для образа — формат, размер, назначение, ожидаемый диапазон и при необходимости SHA-256 без передачи самого содержимого. Отметьте, был ли STOP и работают ли после ошибки повторный init и чтение на 8 МГц.

Не включайте в публичные отчёты приватные дампы, ключи и персональные данные. Для технической диагностики обычно достаточно метаданных, адресов, статусов и хешей.
