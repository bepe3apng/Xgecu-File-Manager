# Запуск из исходников и сборка EXE

[К оглавлению](../README.md)

## 1. Рабочий каталог

Проверенная рабочая копия находится в `F:\XGecu_prog\emmc_continue`, окружение — `F:\XGecu_prog\venv`. Ниже команды PowerShell, выполняемые из `emmc_continue`.

В родительском каталоге есть другие варианты `gui.py` и исследовательские папки. Для этой версии запускайте именно `emmc_continue\gui.py` и используйте именно её `T48_eMMC.spec`.

## 3. Запуск

Из существующего окружения:

```powershell
..\venv\Scripts\python.exe -X utf8 gui.py
```

Проверенный вариант использует Windows с рабочим OpenGL-драйвером. Переносимость текущего USB-слоя на Linux/macOS не реализована: используются winreg, kernel32 и winusb.

Для нового окружения можно установить основные GUI/сборочные зависимости; это инструкция воспроизведения, её выполнение в чистой системе отдельно не проверялось:

```powershell
py -3.11 -m venv ..\venv
..\venv\Scripts\python.exe -m pip install Kivy==2.3.1 kivy_deps.sdl2==0.8.0 kivy_deps.glew==0.3.1 kivy_deps.angle==0.4.0 Pillow==13.0.0 PyInstaller==6.22.3
```

Не пересоздавайте существующее окружение без необходимости. Для проверок окна через win32gui/win32process дополнительно нужен pywin32. Доступность USB не следует из успешного импорта библиотек: T48 должен иметь подходящий WinUSB-драйвер и доступный интерфейс.

## 4. Основная сборка

Закройте ранее запущенный EXE, затем из `emmc_continue`:

```powershell
..\venv\Scripts\python.exe -m PyInstaller --noconfirm T48_eMMC.spec
```

Результат: `dist\T48_eMMC.exe`. Это один оконный файл без консоли. Внутри находятся интерпретатор и упакованные ресурсы. При запуске onefile распаковывает временные файлы; это нормальная работа PyInstaller. Первый запуск может занимать время.

Spec включает:

- точку входа `gui.py`;
- `gui.kv` и весь каталог `assets` как data;
- сбор зависимостей sdl2/glew/angle через `collect_all`;
- hidden import `modes.emmc.autoconfig`;
- runtime hook `packaging_runtime.py`;
- иконку `assets/xgecu_prog.ico`;
- `name='T48_eMMC'`, `console=False`.

`upx=True` в spec не означает, что UPX установлен или применился ко всем компонентам. DLL собираются механизмом PyInstaller и его hooks; не предполагайте, что один список Python-пакетов гарантирует переносимость на любую Windows.

## 5. Пути ресурсов и runtime hook

`FlasherApp.build()` находит KV рядом с `__file__`, поэтому запуск из `dist` не требует `gui.kv` во внешнем текущем каталоге. PNG иконки также определяется относительно модуля. Kivy может иметь дополнительные настройки в профиле пользователя; их наличие не является частью onefile-сборки.

`packaging_runtime.py` устанавливает `site.USER_BASE = sys.prefix`, когда USER_BASE равен None в frozen-приложении. Без этого ранее запуск завершался исключением `expected str, bytes or os.PathLike object, not NoneType` в загрузке Kivy dependencies.

Оставшийся `T48_eMMC_debug.spec` и `T48_eMMC_debug.exe` — диагностические артефакты прежней сборки. Основной результат — `T48_eMMC.exe`; debug-spec может отставать от актуальных настроек.

## 7. Проверка результата

После сборки проверьте запуск из `dist` или другой рабочей папки, появление окна Xgecu Prog и иконки, отсутствие диалога исключения, открытие интерфейса и штатное закрытие. Этот запуск не требует чтения или записи eMMC.

Исторически запуск сборки с иконкой проверен: окно обнаружено, оставалось открытым, присутствовал handle иконки. Позднее EXE пересобран с исправлением перезапуска перед верификацией. Для этой последней пересборки подтверждён успешный PyInstaller; отдельный повторный запуск именно этого файла в сохранённых результатах не зафиксирован.

Размер EXE не закреплён как контракт и меняется с зависимостями и ресурсами. Предыдущая сборка с иконкой имела 30904338 байт; не используйте это значение как контрольную сумму последней версии.

Проверка сборки не подтверждает аппаратную совместимость с любым чипом. Программные и аппаратные проверки перечислены в [TESTING.md](TESTING.md).

## 8. Состав поставки и воспроизводимость

Для пользователя достаточно EXE, подходящего драйвера и оборудования; документацию можно хранить рядом отдельно. Текущая сборка явно не включает каталог docs. Для разработки нужны исходники и тестовые fixtures (`gpt.bin`, scatter-пример), а не только EXE.

Полного lock-файла, автоматического номера версии, подписывания кода и гарантии побитно воспроизводимой сборки здесь не настроено. В рабочей копии `emmc_continue` ранее был неотслеживаемым каталогом Git; сохранение файлов на диске не равнозначно коммиту или публикации. Лицензирование проекта и сторонних ресурсов нужно определять по соответствующим исходным лицензиям; эта документация новую лицензию не назначает.
